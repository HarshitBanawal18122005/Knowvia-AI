# Knowvia AI

An AI-powered research assistant that retrieves relevant Wikipedia content and uses NVIDIA Nemotron to generate answers with supporting sources.

## Features

- AI-powered answer generation using NVIDIA Nemotron
- Wikipedia article retrieval
- SQLite full-text search using FTS5
- Source-based answers and citations
- Interactive Streamlit interface
- Python-based retrieval and indexing pipeline

## Technology Stack

- Python
- Streamlit
- NVIDIA API
- NVIDIA Nemotron
- SQLite
- SQLite FTS5
